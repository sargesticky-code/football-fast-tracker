# Phase 3 source benchmark exit evidence

This is a shadow-only gate. HKJC remains the eligibility authority and live-source rows must use persistent VERIFIED identities; no heartbeat-time fuzzy rematching is allowed.

A source cannot be promoted from shadow/fallback on a one-off response. Evidence must include at least two sources observed in the same live-match window where possible, repeated samples, median and p95 network latency, source-data age, score/minute freshness, coverage, request failure rate, identity match rate, collision count, and exact upstream request count.

Regional or Greater-China placement is not evidence of lower latency. Any such source must have public, rate-safe, technically appropriate access and must be measured from the deployed backend region. If that evidence is absent, record the source as unmeasured rather than faster.

Fast-lane evidence is separate from heavy-lane evidence. Heavy xG/shots/SOT/possession/box touches/big chances/corners/events/momentum remain on source-safe cadence and preserve last-known-good data across transient gaps.

The benchmark itself never changes the production primary.
