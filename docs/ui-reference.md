# UI reference

Fast Tracker App V1 uses the information architecture and interaction patterns
of mature open-source admin dashboards rather than a bespoke spreadsheet-like UI.

Primary reference:
- Kiranism/next-shadcn-dashboard-starter
- MIT licensed
- Next.js 16 + shadcn/ui + responsive dashboard/data-table patterns

Adapted Fast Tracker pattern:
- desktop sidebar + sticky header
- compact KPI cards
- review-first panel
- pipeline-health panel
- filterable match data table
- mobile match cards
- right-side match detail drawer
- dark neutral shadcn-style visual system

The football data, ranking logic, labels and interaction logic are Fast Tracker-specific.
